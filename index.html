Weight parameters (what gets trained)
The weights are a 4-layer MLP value network that estimates how good a board state is:
Input4×4 grid × 16 channels (one-hot log₂ values) = 256
Layer 1 (l1W/l1b)256 → 96 (He init)
Layer 2 (l2W/l2b)96 → 48
Layer 3 (l3W/l3b)48 → 16
Layer 4 (l4W/l4b)16 → 1 state value (Xavier init)
Plus adam_t (Adam optimizer timestep).
Training = self-play games + TD(λ) updates to all W/b matrices. Higher version = more games = stronger AI.

训练流程

① 点击 Train：前端通过 GitHub API 触发 Actions workflow，在云端服务器上运行训练。

② Expectimax 自对弈：Max 节点选最优移动，Chance 节点计算随机生成 2(90%)/4(10%) 的期望值，搜索深度根据空格数自适应（2-5 层）。

③ 神经网络 TD(λ) 训练：MLP 256→96→48→16→1 价值网络，用 TD(λ=0.5, γ=0.95) 计算目标，Adam 优化器 + 经验回放。

④ 渐进式融合：前 30 局纯启发式热身，之后 NN 评估权重逐渐增加到 80%。

⑤ 实时进度：训练过程中每 20 局自动 commit 推送进度文件 js/ai-training-progress.json，前端每 10 秒轮询并刷新 Loss Curve 和 Max Tile 图表。

⑥ 自动部署：训练完成后，GitHub Actions 自动 commit 更新 js/ai-weights.json，所有用户刷新页面即可使用最新的 AI。

⑦ 增量训练：每次训练会加载上一版本的权重继续训练，AI 会持续变强。
