Architecture & Training Pipeline

The AI uses a 4-layer MLP value network (256 → 96 → 48 → 16 → 1) that estimates board state quality through self-play reinforcement learning.

Board Encoding

Each 4×4 grid cell is encoded as a 16-dimensional one-hot vector based on log₂(tile value), producing 256 input features that capture the full board state.

Training Algorithm — Self-Play TD(λ)
  1. Teacher Search: A deterministic Expectimax algorithm (depth 3–4) with chance nodes models tile spawns (2 at 90%, 4 at 10%) to generate move labels for training data.
  2. Policy-Value Network Training: A PyTorch model learns both a policy head (4 move logits) and a value head (normalized state value). Uses Huber loss, gradient clipping (max norm 1.0), and a decaying learning rate schedule.
  3. Unified Value Scaling: The value target is tanh(heuristic_score / 800), providing a bounded [−1, 1] interpretation that works consistently across training and in-browser inference.
  4. Expected Tile API: The trained MLP serves as the evaluation function for the browser-based AI, which uses a depth-3 Expectimax search with the MLP replacing the handcrafted heuristic for move selection.
  5. Fixed-Seed Validation: Every epoch is tested against 50 fixed random seeds; only the best-performing checkpoint becomes the deployed weights, ensuring consistent improvement.
Inference in Browser

During auto-play, the JavaScript engine runs Expectimax search (depth 2–3) using the deserialized MLP weights. At each leaf node, the board is evaluated by the neural network to score positions, enabling the AI to reach 2048+ tiles consistently.

Training Process

① Click Train: Frontend triggers the reproducible v1 Actions workflow on cloud runners.

② Teacher Search: Deterministic Expectimax labels legal moves while chance nodes model 2 (90%) and 4 (10%) tiles.

③ Policy-Value Training: A Python/PyTorch model learns four move logits and a normalized value target, using Huber loss, gradient clipping, and a decaying learning rate.

④ Unified Scale: The value target is tanh(heuristic / 800); the webpage uses the same bounded interpretation, without arbitrary output multipliers.

⑤ Fixed-seed Checkpoint: Every epoch is measured against the same 50 seeds; only the best validation checkpoint becomes js/ai-weights.json.

⑥ Auto Deploy: Actions commits the published v1 weights and progress after validation so page refreshes load the selected checkpoint.

⑦ Versioned Runs: v1 starts from a fixed seed and does not inherit unstable legacy weights.
